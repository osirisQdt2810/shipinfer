# The two gates before the expensive part, instant by instant. Read by both planes.
#
#   scenario <name> <min_hits> <min_height_fraction>
#   instant  <camera>#<track>:<box_height_px> ...      (frames are 1920x1080 throughout)
#
# Heights are pixels of a 1080-tall frame so the fraction is readable: 200 is well over a
# ninth, 50 is well under, and 120 is exactly 1/9 of 1080 -- which is the boundary the
# comparison's strictness decides.

# Three consecutive qualifying frames, then admitted every frame after.
scenario min_hits_3 3 0.1111111111111111
instant cam0#1:200
instant cam0#1:200
instant cam0#1:200
instant cam0#1:200

# HEIGHT FIRST, THEN AGE: five frames too small bank no age at all, so the track still needs
# its three qualifying frames once it comes close. Swap the order and it would be admitted on
# the first usable frame.
scenario too_small_banks_nothing 3 0.1111111111111111
instant cam0#1:50
instant cam0#1:50
instant cam0#1:50
instant cam0#1:50
instant cam0#1:50
instant cam0#1:200
instant cam0#1:200
instant cam0#1:200
